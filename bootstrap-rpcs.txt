# WQPU trusted first-contact RPC gateways.
#
# These addresses locate/read the WQPU blockchain only. They are NOT compute
# peers and they are never treated as network authorities. Every candidate is
# verified by the client before use; a successful endpoint is then saved in the
# machine's local verified RPC addrbook for later starts.
#
# Compute/storage peers are discovered exclusively from the authenticated
# on-chain registry after blockchain access has been verified.
#
# Production entries must use HTTPS or WSS. Ship several independent gateways
# operated by different parties/regions. No single RPC or project-owner VPS may
# be required for WQPU to operate. Full WQPU chain nodes additionally use
# bootstrap-p2p.txt + CometBFT PEX + persistent config/addrbook.json.
#
# One production RPC URL per line will be added when public WQPU gateways exist.
